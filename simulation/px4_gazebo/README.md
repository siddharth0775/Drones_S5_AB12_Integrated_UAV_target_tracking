# PX4 + Gazebo Object Tracking Simulation

This module contains the PX4 SITL and Gazebo implementation used to
validate the UAV object-tracking and following system.

## Components

- PX4 SITL
- Gazebo simulation
- X500 UAV
- Camera-based perception
- Offboard control
- Velocity-based UAV control
